## 1. 이 AI는 무엇을 배우고 있나요?

### 목표

사용자가 **"정보처리기사 시험이 3주 뒤야, 준비 계획 짜줘"** 같은 요청을 하면, AI가 오늘 할 일과 미래 일정을 정리해 **구조화된 플랜**으로 돌려주는 능력을 학습합니다.

```
사용자 입력: "정보처리기사 필기 D-21, 1과목부터 5과목까지 준비해줘"

AI 출력:
{
  "summary_text": "정보처리기사 필기 3주 준비 플랜입니다...",
  "todos": [
    {"title": "1과목 요점 정리", "due_date": "2026-06-10", "tags": ["정처기", "오늘"]}
  ],
  "calendar_events": [
    {"title": "1·2과목 기출 집중",   "due_date": "2026-06-17", "tags": ["정처기", "미래"]},
    {"title": "전범위 실전 풀이",     "due_date": "2026-06-24", "tags": ["정처기", "미래"]},
    {"title": "정보처리기사 필기 시험", "due_date": "2026-07-01", "tags": ["정처기", "시험"]}
  ]
}
```

**핵심 규칙 (C5 분기)**:

- `todos` = **오늘** 할 일만
- `calendar_events` = **미래** 날짜 일정만

### 응답 유형 4가지

| 유형 | 설명 | 언제 쓰나 |
|------|------|-----------|
| **plan** | 즉시 계획 생성 | 시험 날짜·과목 정보가 충분할 때 |
| **follow_up** | 추가 질문 1개 | 정보 부족 (예: 시험 날짜 미제공) |
| **out_of_scope** | 거절 | 계획 세우기와 무관한 요청 |
| **chit_chat** | 일상 대화 응답 | 인사·잡담 |

> 플랜만 학습하면 "오늘 날씨 어때?"에도 계획을 토해냅니다. 이를 막기 위해 거절·잡담 데이터(**distractor**)를 함께 학습시킵니다.

## 4. 정성 평가

> **정성 평가**란 "이 플랜이 실제로 쓸 만한가?"처럼 수치만으로 판단하기 어려운 품질을 사람 또는 AI 심사위원이 1~5점으로 평가하는 방식입니다.

### 4.1 평가 기준 (M1~M4)

| 차원 | 5점 기준 | 1점 기준 | 왜 중요한가 |
|------|---------|---------|------------|
| **M1 분배 합리성** | 난이도·맥락 반영 (어려운 과목에 더 많은 시간) | 1단원·2단원... 기계적 균등 배분 | 기계적 플랜은 실제로 쓸모없음 |
| **M2 시간 현실성** | 소요시간 추정 현실적, 여유 시간 포함 | 하루에 5과목 완성 같은 비현실적 플랜 | 실행 불가능한 계획은 의미 없음 |
| **M3 순서 논리** | 개념 → 기출 → 실전 순서 준수 | 시험 전날 개념 시작 | 순서가 틀리면 학습 효율 저하 |
| **M4 완결성** | 이 플랜대로 하면 목표 달성 가능 | 중요 과목 누락, 시험일 전에 플랜 종료 | 가장 핵심 — 목표 달성 여부 |

**판정 기준**:

| 의미 평균 | 판정 |
|----------|------|
| 4.0 이상 | ACCEPT — 학습 데이터로 채택 |
| 3.0~3.9 | FIX — 수정 후 재검토 |
| 3.0 미만 | DROP — 폐기 |

### 4.2 실제 출력 예시

**성공 사례 — plan, 파싱 성공, 정합성 통과**

```
입력: "정보처리기사 실기 D-7, SQL 약점 있음"

출력:
- summary: "실기 준비 플랜입니다. SQL 응용 보완 우선 진행."
- todos (오늘):
    · SQL 약점 확인    (2026-06-09, 태그: 정처기, 실기, 오늘)
    · 실기 범위 점검    (2026-06-09, 태그: 정처기, 실기, 오늘)
- calendar_events (미래):
    · SQL 기출 풀이     (2026-06-10, 태그: 정처기, 실기, 미래)
    · 프로그래밍 마무리 (2026-06-14, 태그: 정처기, 실기, 미래)
    · 정처기 실기 시험  (2026-06-19, 태그: 정처기, 시험)
```

C5 분기 정확 / 날짜 형식 정상 / 한국어 태그 / 순서 논리 정상 → **M1~M4 모두 양호**

## 5. 학습 설정 요약

| 설정 | 값 | 이유 (간단 설명) |
|------|-----|-----------------|
| 학습 방식 | **LoRA (어댑터 추가)** | 전체 재학습 대비 비용 1/10, 품질 동급 |
| 양자화 | **4bit (QLoRA)** | GPU 메모리 절약 — 7B 모델을 단일 GPU에서 실행 가능 |
| 손실 계산 | **응답 부분만** | 사용자 질문은 제외하고 AI 답변만 학습 |
| 학습률 | 2e-4 | LoRA 표준 권장값 |
| 에폭 수 | **2회** | 1회 미만이면 덜 배움 / 3회 이상이면 암기 위험 |
| 최대 길이 | 4,096 토큰 | 모든 샘플 커버 (최장 1,428자 < 4,096) |
| GPU | RunPod A100 40GB | |
| 기반 모델 | Qwen2.5-7B-Instruct | 실제 서비스에 올라갈 모델 |
| Teacher 모델 | Qwen2.5-14B-Instruct | 학습 데이터 합성용 (더 크고 정확한 모델) |
