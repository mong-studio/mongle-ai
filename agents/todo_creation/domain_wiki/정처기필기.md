# 정보처리기사 필기 도메인 위키

## 시험 개요
- **형식**: 객관식 4지 택일형, 과목당 20문항 × 5과목 = 총 100문항
- **시간**: 150분
- **합격 기준**: 과목당 40점 이상 + 전과목 평균 60점 이상
- **과목**: 소프트웨어설계 / 소프트웨어개발 / 데이터베이스구축 / 프로그래밍언어활용 / 정보시스템구축관리

## 학습 전략
- **핵심**: 문제은행 방식이므로 기출 3개년 반복이 가장 효과적
- **우선순위**: 데이터베이스구축 · 프로그래밍언어활용에서 오답 집중 관리
- **과락 위험 과목**: 정보시스템구축관리 — 40점 미달 방지 필수
- **비전공자 권장 기간**: 7~14일 (하루 2~3시간)
- **전공자/개발자 권장 기간**: 5~7일

## 기간별 플랜 패턴

### 14일 플랜 (비전공자, 하루 3시간)
| 기간 | 활동 |
|------|------|
| 1~2일 | 소프트웨어설계 기출풀기 + 개념서 1회독 |
| 3~4일 | 소프트웨어개발 기출풀기 + 오답정리 |
| 5~6일 | 데이터베이스구축 기출풀기 + 오답노트 |
| 7~8일 | 프로그래밍언어활용 기출풀기 + 오답노트 |
| 9~10일 | 정보시스템구축관리 기출풀기 (과락 방지 집중) |
| 11~12일 | 전과목 오답 반복 회독 |
| 13~14일 | 모의고사 100문항 × 2회 + 최종 오답 정리 |

### 7일 플랜 (직장인/전공 기초, 하루 2.5시간)
| 기간 | 활동 |
|------|------|
| 1~2일 | 소프트웨어설계·개발 기출 핵심 오답 압축 |
| 3~4일 | 데이터베이스구축 기출풀기 + SQL 집중 |
| 5일 | 프로그래밍언어활용 + 정보시스템구축관리 기출 |
| 6일 | 전과목 오답 반복 |
| 7일 | 모의고사 100문항 + 시간 감각 훈련 |

## 추천 태스크 이름 (20자 이내, 플래너 참고용)
- 소프트웨어설계 기출풀기
- 소프트웨어개발 기출풀기
- 데이터베이스구축 기출풀기
- 프로그래밍언어활용 기출
- 정보시스템구축관리 기출
- 정처기 필기 오답정리
- 정처기 필기 오답 반복
- 정처기 모의고사 100문항
- 정처기 필기 개념서 읽기
- 과목별 오답노트 작성

## 합격 경험 패턴 요약
- **3일 합격**: 기출 집중 반복, 개념 최소화, 익숙해지기 전략 (전공 기초 필수)
- **5일 합격**: 개념서 1일 + 기출 4일 반복, 평균 85점
- **14일 합격**: 과목별 순서, 오답 반복, 평균 70점대 (비전공자 표준)
- **실패 패턴**: 풀이량 부족 + 정보시스템구축관리 과락

## 플랜 생성 주의사항
- 기간이 짧으면(5일 이하) 개념서 생략, 기출 위주로만 구성
- 기간이 길면(14일+) 과목별 순서 배분 + 마지막 2일은 모의고사
- "공부"처럼 모호한 동사보다 "기출풀기", "오답정리" 같은 행동 단위로 작성
- 회계·경영·어학 등 관련 없는 과목은 절대 추가하지 않음
