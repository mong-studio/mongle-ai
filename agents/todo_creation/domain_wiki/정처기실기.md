# 정보처리기사 실기 도메인 위키

## 시험 개요
- **형식**: 필답형 (단답식·서술형·코딩)
- **시간**: 150분
- **합격 기준**: 100점 만점 60점 이상
- **과목**: 정보처리실무 (12개 영역)

## 12개 학습 영역
1. 요구사항 확인
2. 데이터 입출력 구현
3. 통합 구현
4. 서버프로그램 구현
5. 인터페이스 구현
6. 화면 설계
7. 애플리케이션 테스트 관리
8. SQL 응용
9. 소프트웨어 개발 보안 구축
10. 프로그래밍 언어 활용
11. 응용 SW 기초 기술 활용
12. 제품소프트웨어 패키징

## 학습 전략 — 중요도 우선순위

### 최우선 (합산 약 12문항 ≈ 60% 비중)
- **SQL 응용**: SELECT·JOIN·서브쿼리·DDL·DML 기출 위주
- **프로그래밍 언어 활용**: C언어(포인터), Java(OOP), Python 손코딩 반복

### 2순위 (암기 + 서술형 키워드)
- **소프트웨어 개발 보안**: DES·AES·SEED·해시·XSS·SQL인젝션 등 키워드
- **애플리케이션 테스트 관리**: 블랙박스/화이트박스, 테스트 유형
- **디자인 패턴**: GoF 패턴 이름 + 한 줄 설명

### 3순위 (이해 + 서술)
- 나머지 7개 영역: 개념 이해 + 기출 오답 관리

## 기간별 플랜 패턴

| 기간 | 활동 |
|------|------|
| 1~7일 | 개념서 1회독 (수제비 or 시나공 실기) |
| 8~14일 | SQL + 프로그래밍 기출풀기 + 오답노트 |
| 15~18일 | 보안·테스트·패턴 키워드 암기 |
| 19~21일 | 서술형 키워드 + 전범위 모의고사 |

### 10일 플랜 (단기, 하루 3시간)
| 기간 | 활동 |
|------|------|
| 1~3일 | SQL 응용 기출풀기 집중 |
| 4~6일 | C/Java/Python 손코딩 기출 연습 |

## 합격 경험 패턴 요약
- **21일 합격**: SQL·프로그래밍 먼저, 마지막 주 보안+서술형 반복
- **3주 합격 95점**: 개념서 + 기출 + 오답노트 + 코딩 집중
- **실패 패턴**: SQL·프로그래밍 풀이량 부족, 보안 암기 미흡
- **공백 6개월 후 실패**: SQL 부족으로 점수 손실

## 플랜 생성 주의사항
- SQL과 프로그래밍(C/Java/Python)을 반드시 태스크에 포함할 것
- "실기 공부"처럼 뭉뚱그리지 말고 "SQL 응용 기출풀기" 처럼 구체적으로
- 보안 파트는 암기 위주, 키워드 숙지에 집중
- 회계·어학·경영 등 관련 없는 과목은 절대 추가하지 않음
- 필기 합격 후 실기를 준비하는 경우이므로 필기 내용을 반복하지 않음
