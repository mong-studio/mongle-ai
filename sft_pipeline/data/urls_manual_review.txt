# 사람 검수 전용 - 자동 크롤러(run_crawl.py)에 바로 넣지 말 것.
#
# 왜 분리했나:
# - 이 소스들은 robots에서 AI 봇(ClaudeBot/GPTBot/CCBot 등)을 명시 차단하거나(네이버 블로그/지식iN/디시),
#   일반 봇까지 전면 차단(네이버 카페/메인)하거나, 약관상 자동수집을 금지한다.
# - 우리 크롤러의 UA("mongle-sft-crawler")는 그 AI 봇 이름이 아니라서 urllib robots 판정은
#   관대한 '*' 규칙으로 떨어져 "통과"해 버린다. 즉 코드의 robots-skip이 이들을 막아주지 못한다.
#   → 사이트가 기계로 표명한 'AI 크롤러 사절'을 UA만으로 우회하는 셈(잡코리아 vs 사람인 판례에서
#     'UA 위장 = 악의적 접근'으로 불리하게 본 패턴). 그래서 자동 수집 대상에서 제외한다.
# - 기술적으로도: 네이버 블로그 본문은 iframe(PostView), velog는 SPA, 카페는 로그인벽 → 정적 fetch로 빈 본문.
#
# 사용 방법(권장): 사람이 브라우저로 직접 열어 읽고, 원문 복붙 금지·요약/재서술로
#   raw_cases.csv 에 손으로 입력. 필요하면 네이버는 공식 Open API(검색)로 URL만 확보.
#   디시는 비속어/광고/도배 노이즈가 많아 강한 필터·검수 필수.
# - 출처: 2026-06-04 deep-research.
